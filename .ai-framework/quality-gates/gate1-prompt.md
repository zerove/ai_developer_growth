# Gate 1: Prompt 设计审查

> 语言无关的 Prompt 设计审查标准

---

## 检查项

| # | 检查项 | 验证方式 | 通过标准 |
|---|--------|----------|----------|
| 1.1 | 名称格式 | 人工检查 | kebab-case，无特殊字符 |
| 1.2 | 描述完整 | 人工检查 | 一句话说明核心职责 |
| 1.3 | 指令具体性 | 逐条检查 | 每条指令可验证 |
| 1.4 | 工具最小化 | 与职责对比 | 无冗余工具 |
| 1.5 | 职责唯一性 | 与现有 agent 对比 | 无重叠 |

---

## 指令可验证性检查

每条指令必须满足以下至少一项：

| 验证方式 | 示例 |
|----------|------|
| **文件检查** | "修改 `src/main.py`" → 文件存在 |
| **命令检查** | "运行 `pytest`" → 命令可执行 |
| **输出检查** | "输出 JSON 格式" → 格式可验证 |
| **状态检查** | "测试通过" → 状态可检查 |

---

## 审查清单

### 基本信息

- [ ] Agent 名称符合 kebab-case 格式
- [ ] 描述是一句话，不超过 100 字
- [ ] 工具列表不超过 10 个

### 指令质量

- [ ] 每条指令包含具体的工具/文件/函数名
- [ ] 每条指令有明确的成功/失败判定
- [ ] 指令按逻辑顺序排列
- [ ] 无重复或矛盾的指令

### 职责边界

- [ ] 与现有 agent 无职责重叠
- [ ] 职责范围清晰、可边界
- [ ] 无隐含职责

---

## 审查结果

| 状态 | 说明 |
|------|------|
| ✅ PASS | 所有检查项通过 |
| ⚠️ WARNING | 有警告，可酌情通过 |
| ❌ FAIL | 有严重问题，必须修复 |

---

*本检查项适用于任何语言的 agent 定义。*
