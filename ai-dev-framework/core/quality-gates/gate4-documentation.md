# Gate 4: 资产更新审查

> 语言无关的资产更新审查标准

---

## 概述

Gate 4 确保每次迭代的成果被正确记录到项目资产中。

---

## 检查项

| # | 检查项 | 验证方式 | 通过标准 |
|---|--------|----------|----------|
| 4.1 | CONTEXT.md | 检查文件存在性 | 最新状态已更新 |
| 4.2 | ADR.md | 检查关键决策记录 | 新决策已记录 |
| 4.3 | AGENTS.md | 检查 agent 定义 | 新 agent 已索引 |
| 4.4 | 文档同步 | 与代码一致性检查 | 文档与代码一致 |
| 4.5 | CHANGELOG | 检查更新日志 | 变更已记录 |

---

## 必需文件

### CONTEXT.md

```markdown
# 项目上下文

## 项目状态
- 当前阶段: {阶段名称}
- 最后更新: {日期}

## 最新变更
- {变更1}
- {变更2}

## 下一步计划
- {计划1}
- {计划2}
```

### ADR.md

```markdown
# 架构决策记录

## ADR-{编号}: {决策标题}
- 日期: {日期}
- 状态: {提议/接受/已废弃}

### 上下文
{决策背景}

### 决策
{决策内容}

### 影响
{正面影响}
{负面影响}
```

### AGENTS.md

```markdown
# Agent 定义索引

| Agent | 职责 | 文件 |
|-------|------|------|
| {name} | {description} | {path} |
```

---

## 审查清单

### 项目上下文

- [ ] CONTEXT.md 存在且包含最新状态
- [ ] 最后更新日期与现实一致
- [ ] 下一步计划反映真实优先级

### 架构决策

- [ ] 重大决策已记录在 ADR.md
- [ ] ADR 包含上下文、决策、影响
- [ ] 废弃的 ADR 已标记

### Agent 定义

- [ ] 新 agent 已添加到 AGENTS.md
- [ ] agent 定义与模板一致
- [ ] 修改的 agent 已更新

### 文档一致性

- [ ] README 与项目实际结构一致
- [ ] API 文档与实际接口一致
- [ ] 示例代码与实际 API 一致

---

## 审查结果

| 状态 | 说明 |
|------|------|
| ✅ PASS | 所有资产已更新 |
| ⚠️ WARNING | 部分资产需更新 |
| ❌ FAIL | 必须更新资产再通过 |

---

*本检查项适用于任何语言的资产更新审查。*
