# Agent Prompt 模板

本文档提供 agent 定义的标准模板。

---

## 使用方法

1. 复制下方模板
2. 替换 `{占位符}` 为实际内容
3. 删除不适用的可选部分
4. 按照质量门禁审查

---

## 标准模板

```markdown
## agent: {agent-name} ({中文名称})
{一句话描述 agent 的核心职责和作用域}

### 指令
1. {具体指令1: 使用明确的工具名、文件路径、函数名}
2. {具体指令2: 可验证的行为规范}
3. {具体指令3: 禁止的行为}
...

### 工具
- {tool1}
- {tool2}
...

### 约束
- {约束1: 明确的限制条件}
- {约束2: 禁止的操作}
...
```

---

## 示例

```markdown
## agent: code-reviewer (代码审查员)
审查代码变更，确保代码质量和安全。

### 指令
1. 使用 `git diff HEAD~1` 获取最新变更
2. 检查代码风格是否符合项目规范
3. 检查是否有安全漏洞
4. 输出审查报告

### 工具
- git
- ruff
- pytest

### 约束
- 不修改任何代码，仅报告问题
- 忽略测试文件
```

---

## 质量检查清单

- [ ] 名称符合 kebab-case 格式
- [ ] 描述是一句话，不超过 100 字
- [ ] 每条指令包含具体的工具/文件/函数名
- [ ] 每条指令有明确的成功/失败判定
- [ ] 工具列表不超过 10 个
- [ ] 与现有 agent 无职责重叠

---

*本模板适用于任何语言的 agent 定义。*
