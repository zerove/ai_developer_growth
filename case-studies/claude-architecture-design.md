## 洞察

### 1. Claude 适合长文本设计

- 200K context 能容纳完整需求文档
- 能记住之前的讨论，保持一致性
- 适合需要全局视角的架构设计

### 2. 对比分析是强项

让 Claude 对比多种方案，比直接问"用什么"更有效：
- 方案 A vs 方案 B vs 方案 C
- 每种方案的优劣分析
- 基于约束条件的推荐

### 3. 人负责最终决策

- AI 提供方案选项和分析
- 人根据实际情况做决策
- AI 帮助细化决策后的设计

### 4. 迭代式设计

```
粗略设计 → AI 细化 → 人工调整 → AI 验证 → 最终方案
```
