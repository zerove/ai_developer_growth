# ADR-005: AI 导航系统架构

## 状态

**提议** (2026-07-21)

## 背景

随着知识库内容增长，用户需要更智能的方式来发现和学习相关内容。传统的目录结构和搜索已经不能满足个性化需求。

### 问题

1. **信息过载**: 35+ 篇文档，15+ 个案例，用户不知道从哪里开始
2. **个性化缺失**: 不同背景的开发者需要不同的学习路径
3. **发现困难**: 相关内容分散在不同目录，难以关联

### 约束

- 必须保持知识库的静态特性 (不需要数据库)
- 必须支持离线使用
- 必须尊重用户隐私 (不收集个人信息)

## 决策

### 方案对比

| 方案 | 优势 | 劣势 | 复杂度 |
|------|------|------|--------|
| 方案 A: 基于规则的推荐 | 简单、透明 | 不够智能 | 低 |
| 方案 B: 基于向量的推荐 | 智能、个性化 | 需要 embedding 模型 | 中 |
| 方案 C: 混合方案 | 平衡 | 需要调优 | 中 |

### 选择方案 C: 混合方案

采用分层架构：

```
┌─────────────────────────────────────────┐
│              用户界面层                  │
│  (学习路径推荐、相关内容、智能搜索)     │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐
│              推荐引擎层                  │
│  ┌─────────────┐  ┌─────────────────┐  │
│  │ 规则引擎    │  │ 向量推荐引擎    │  │
│  │ (静态规则)  │  │ (动态推荐)      │  │
│  └─────────────┘  └─────────────────┘  │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐
│              数据层                      │
│  (文档元数据、用户标签、学习路径)       │
└─────────────────────────────────────────┘
```

### 核心组件

1. **学习路径模板**: 预定义的学习路径
2. **相关内容推荐**: 基于元数据的关联推荐
3. **智能搜索**: 结合关键词和语义的搜索
4. **用户画像**: 基于行为的用户标签 (可选)

## 实现计划

### Phase 1: 基础推荐 (2 周)

- 学习路径模板
- 基于标签的内容推荐
- 面包屑导航增强

### Phase 2: 智能推荐 (4 周)

- 向量化文档
- 语义搜索
- 个性化推荐

### Phase 3: 高级功能 (8 周)

- 用户行为追踪
- 协同过滤
- A/B 测试框架

## 后果

### 正面

- 用户更容易发现相关内容
- 个性化学习体验
- 知识库利用率提升

### 负面

- 增加维护复杂度
- 需要持续优化推荐算法
- 可能引入性能开销
