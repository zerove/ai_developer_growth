# 贡献者激励计划

## 贡献等级

| 等级 | 要求 | 奖励 |
|------|------|------|
| 🌱 入门贡献者 | 提交 1 个有效案例或文档 | 项目致谢 + 专属标签 |
| 🌿 活跃贡献者 | 累计 5 个有效贡献 | README 贡献者列表 + 优先 Review |
| 🌳 核心贡献者 | 累计 15 个贡献 + 参与治理 | 协作者权限 + 项目决策投票权 |
| 🏆 社区导师 | 指导 3+ 新贡献者 | 专属徽章 + 年度感谢 |

## 贡献类型与积分

| 贡献类型 | 积分 | 说明 |
|----------|------|------|
| 案例提交 | 10 分 | 通过验证的真实案例 |
| 文档撰写 | 8 分 | 新文档或重大改进 |
| 工具评测 | 6 分 | 完整的工具对比报告 |
| Bug 修复 | 5 分 | 修复代码或文档问题 |
| 代码示例 | 7 分 | 可运行的参考实现 |
| 翻译 | 4 分 | 文档翻译 |
| 反馈建议 | 2 分 | 有价值的问题反馈 |

## 月度之星

每月评选 Top 3 贡献者:
- 🥇 第一名: 项目首页展示 + 推荐信
- 🥈 第二名: 技术博客采访机会
- 🥉 第三名: 开源工具赞助

## 贡献流程

1. **发现**: 在 Issues 中找到 `good-first-issue` 标签
2. **认领**: 评论 Assign 给自己
3. **开发**: Fork → Branch → Commit → PR
4. **Review**: 至少 1 位维护者审核
5. **合并**: 通过 CI + 质量门禁
6. **积分**: 自动计入贡献者排行榜

## 质量标准

所有贡献必须满足:
- [ ] 格式符合 `CONTRIBUTING.md` 规范
- [ ] 通过自动化检查 (ruff, link audit)
- [ ] 包含真实场景描述
- [ ] 有可验证的结果或数据

## 特别激励

- **首个贡献**: 额外 +5 分 (鼓励新人)
- **连续贡献**: 连续 4 周每周贡献 +10 分
- **高质量案例**: 被标记为 "Featured" +15 分
