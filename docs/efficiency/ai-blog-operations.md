# AI 辅助技术博客运营

## 核心原则

AI 博客运营 = 写作 + SEO + 社区 + 数据分析

## 运营流程

```
内容规划 → 写作发布 → SEO 优化 → 社区推广 → 数据分析
```

## Prompt 技巧

### 1. 内容规划

```markdown
请规划博客内容:
- 主题: Python 技术
- 频率: 每周 2 篇
- 类型: 教程、实战、原理
```

### 2. 文章写作

```markdown
请撰写技术文章:
- 主题: FastAPI 入门
- 目标读者: 初中级开发者
- 结构: 介绍-安装-使用-进阶-总结
```

### 3. SEO 优化

```markdown
请优化文章 SEO:
- 标题优化
- 关键词布局
- 内链设置
```

## 内容策略

### 1. 内容类型

```
教程类: 手把手教学
实战类: 项目开发
原理类: 深入分析
经验类: 踩坑分享
```

### 2. 内容矩阵

```
入门 → 进阶 → 高级 → 专家
```

### 3. 内容复用

```
一篇长文 → 多篇短文 → 视频 → 社交媒体
```

## SEO 技巧

### 1. 关键词研究

```
工具: Google Keyword Planner, Ahrefs
方法: 竞争分析、趋势分析
```

### 2. 页面优化

```
标题 → 描述 → 标签 → 内容 → 链接
```

### 3. 技术 SEO

```
速度 → 移动端 → 结构化数据 → Sitemap
```

## 效率提升

### 1. 批量写作

批量生成同主题文章。

### 2. 模板化

文章模板复用。

### 3. 数据驱动

基于数据调整策略。
