# AI 上下文窗口管理标准 (Context Window Management)

> 上下文窗口是 AI 的"工作记忆"。管理不当会导致信息丢失或成本浪费。

---

## 1. 核心挑战

| 挑战 | 影响 | 解决方案 |
|------|------|----------|
| **窗口有限** | 无法一次加载整个项目 | 分层上下文 |
| **成本高昂** | 长上下文费用高 | 精简上下文 |
| **信息过载** | 噪声干扰 AI | 优先级排序 |
| **状态丢失** | 长会话丢失上下文 | 定期刷新 |

---

## 2. 分层上下文策略

### 2.1 三层上下文模型

```
Layer 1: 项目全局 (始终提供, ~2K tokens)
├── README.md 摘要
├── CONTEXT.md 状态
├── 代码规范要点
└── 项目结构概览

Layer 按需提供, ~5K tokens)
├── 相关模块接口
├── 依赖关系
├── 数据模型
└── 最近变更

Layer 3: 任务级 (每次提供, ~3K tokens)
├── 当前文件内容
├── 相关函数
├── 测试用例
└── 错误信息
```

### 2.2 上下文预算分配

| 上下文类型 | 建议占比 | 最大 tokens |
|------------|----------|-------------|
| **项目全局** | 15% | 3,000 |
| **模块上下文** | 40% | 8,000 |
| **任务上下文** | 35% | 7,000 |
| **缓冲区** | 10% | 2,000 |
| **总计** | 100% | 20,000 |

## 3. 上下文优化技术

### 3.1 信息精简

```python
# ❌ 不好: 发送完整文件
prompt = f"修改这个函数:\n{full_file_content}"

# ✅ 好: 只发送相关部分
prompt = f"修改这个函数:\n{function_code}\n\n调用者:\n{callers}\n\n测试:\n{tests}"
```

### 3.2 摘要策略

| 内容类型 | 处理方式 |
|----------|----------|
| 代码文件 | 只发送相关函数 + 接口 |
| 文档 | 发送摘要 + 关键段落 |
| 日志 | 发送最后 50 行 + 错误行 |
| 测试 | 发送失败测试 + 相关断言 |

### 3.3 优先级排序

```
优先级 1 (必须):
- 当前编辑的文件
- 直接依赖的接口
- 相关测试用例

优先级 2 (重要):
- 模块结构
- 最近 git 变更
- 错误日志

优先级 3 (可选):
- 项目 README
- 架构文档
- 历史决策
```

## 4. 会话管理

### 4.1 长会话策略

| 策略 | 实现方式 | 适用场景 |
|------|----------|----------|
| **定期总结** | 每 20 轮总结一次 | 长时间开发 |
| **状态快照** | 保存关键决策 | 多步骤任务 |
| **上下文重置** | 新任务时重置 | 任务切换 |

### 4.2 上下文刷新检查清单

```
每次新任务开始时:
□ 提供项目当前状态
□ 提供相关模块接口
□ 提供代码规范要点
□ 明确任务边界和约束
□ 提供示例输入/输出
```

## 5. 成本控制

### 5.1 上下文成本估算

| 模型 | 输入成本/1K tokens | 20K 上下文成本 |
|------|-------------------|----------------|
| Claude 4 | $0.015 | $0.30 |
| GPT-5 | $0.010 | $0.20 |
| Haiku | $0.00025 | $0.005 |

### 5.2 成本优化策略

```
策略 1: 精简上下文
  从 20K tokens → 8K tokens
  成本降低 60%

策略 2: 使用经济模型
  从 Claude 4 → Haiku
  成本降低 98%

策略 3: 缓存重复上下文
  使用系统提示缓存
  成本降低 30-50%
```

## 6. 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| AI 忘记之前的信息 | 上下文溢出 | 定期总结 + 状态快照 |
| AI 生成不一致代码 | 上下文不完整 | 提供完整接口定义 |
| 成本超预算 | 上下文过长 | 精简 + 使用经济模型 |
| 响应速度慢 | 上下文过长 | 减少上下文 + 缓存 |
