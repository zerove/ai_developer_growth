# AI 辅助数据工程

## 核心原则

数据工程 = 数据采集 + 数据处理 + 数据存储 + 数据服务

## 数据管道

### 1. ETL 流程

```
Extract (采集) → Transform (转换) → Load (加载)
```

### 2. 实时流处理

```
Kafka → Flink/Spark Streaming → 数据存储
```

### 3. 批处理

```
HDFS/S3 → Spark → 数据仓库
```

## Prompt 技巧

### 1. ETL 脚本

```markdown
请生成 ETL 脚本:
- 从 CSV 读取数据
- 数据清洗
- 格式转换
- 加载到数据库
```

### 2. 数据模型

```markdown
请设计数据仓库模型:
- 维度表: 用户、商品、时间
- 事实表: 订单、访问
- 星型模型
```

### 3. 数据质量

```markdown
请生成数据质量检查:
- 完整性检查
- 一致性检查
- 准确性检查
```

## 工具选择

### 1. 批处理

```
Apache Spark: 大规模数据处理
Apache Hive: SQL 查询
dbt: 数据转换
```

### 2. 流处理

```
Apache Kafka: 消息队列
Apache Flink: 实时计算
Apache Storm: 流处理
```

### 3. 数据存储

```
数据湖: S3, HDFS
数据仓库: Redshift, BigQuery
OLAP: ClickHouse, Druid
```
