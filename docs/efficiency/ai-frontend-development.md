# AI 辅助前端开发

## 核心原则

AI 前端 = 组件设计 + 状态管理 + 交互优化

## 组件设计

### 1. 组件结构

**原子设计:**
```
原子 → 分子 → 有机体 → 模板 → 页面
```

**AI 生成组件:**
```markdown
请生成一个用户卡片组件:
- 显示头像、姓名、邮箱
- 响应式设计
- 支持点击事件
```

### 2. 状态管理

**方案选择:**
```
局部状态: useState/useReducer
全局状态: Redux/Zustand
服务端状态: React Query/SWR
```

## Prompt 技巧

### 1. 组件生成

```markdown
请生成 React 组件:
- 功能: 用户表单
- 字段: name, email, phone
- 验证: 必填、格式校验
- 样式: Ant Design
```

### 2. 样式生成

```markdown
请生成 CSS:
- 响应式布局
- 深色模式
- 动画效果
```

### 3. 交互优化

```markdown
请优化这个交互:
- 加载状态
- 错误处理
- 无障碍支持
```

## 最佳实践

### 1. 性能优化

**策略:**
```
懒加载 → 虚拟列表 → Memo → 代码分割
```

### 2. 响应式设计

**策略:**
```
移动优先 → 断点设计 → 弹性布局
```

### 3. 无障碍设计

**原则:**
- 语义化 HTML
- ARIA 属性
- 键盘导航

## 工具推荐

### 1. 组件库

```
React: Ant Design, Material UI, Chakra UI
Vue: Element Plus, Vuetify, Naive UI
```

### 2. 样式工具

```
Tailwind CSS: 原子化 CSS
Styled Components: CSS-in-JS
Sass: CSS 预处理
```

### 3. 构建工具

```
Vite: 快速构建
Webpack: 传统构建
esbuild: 极速构建
```

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 渲染慢 | 组件重渲染 | Memo 优化 |
| 包太大 | 未分割 | 代码分割 |
| 样式冲突 | 作用域问题 | CSS Modules |

## 效率提升

### 1. 组件复用

建立组件库，标准化复用。

### 2. 模板化

常见页面模板化，快速搭建。

### 3. 自动化测试

组件测试自动化，保证质量。
