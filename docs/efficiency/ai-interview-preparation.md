# AI 辅助技术面试

## 核心原则

AI 面试准备 = 知识梳理 + 模拟练习 + 反馈改进

## 准备流程

```
知识梳理 → 题目练习 → 模拟面试 → 反馈改进 → 正式面试
```

## Prompt 技巧

### 1. 知识梳理

```markdown
请梳理 [技术] 知识点:
- 核心概念
- 常见问题
- 最佳实践
```

### 2. 题目练习

```markdown
请出 [技术] 面试题:
- 难度: 中等
- 类型: 算法、系统设计
- 数量: 5 道
```

### 3. 模拟面试

```markdown
请模拟技术面试:
- 职位: 后端工程师
- 问题: 系统设计
- 反馈: 评分和建议
```

## 面试类型

### 1. 算法面试

```
数据结构 → 算法设计 → 复杂度分析 → 优化
```

### 2. 系统设计

```
需求分析 → 高层设计 → 详细设计 → 扩展讨论
```

### 3. 行为面试

```
STAR 方法 → 项目经验 → 团队协作 → 解决问题
```

## 最佳实践

### 1. 算法准备

```
LeetCode → 常见题型 → 限时练习
```

### 2. 系统设计

```
常见系统 → 设计模式 → 权衡分析
```

### 3. 项目经验

```
项目亮点 → 技术难点 → 解决方案 → 成果展示
```

## 效率提升

### 1. 针对性练习

根据目标职位针对性准备。

### 2. 模拟面试

使用 AI 模拟面试场景。

### 3. 反馈迭代

每次练习后获取反馈并改进。
