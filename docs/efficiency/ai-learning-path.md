# AI 辅助技术学习路径

## 核心原则

AI 学习 = 目标设定 + 路径规划 + 实践验证 + 持续迭代

## 学习流程

```
目标设定 → 知识评估 → 路径规划 → 学习实践 → 反馈调整
```

## Prompt 技巧

### 1. 路径规划

```markdown
请规划学习路径:
- 目标: 全栈工程师
- 当前水平: 初级后端
- 时间: 6 个月
```

### 2. 知识评估

```markdown
请评估知识水平:
- 技术: Python, React
- 项目: 2 个
- 目标: 高级工程师
```

### 3. 学习计划

```markdown
请制定学习计划:
- 周目标: 学习 FastAPI
- 每日时间: 2 小时
- 实践项目: REST API
```

## 学习路径

### 1. 前端路径

```
HTML/CSS → JavaScript → React → TypeScript → Next.js
```

### 2. 后端路径

```
Python/Java → Web 框架 → 数据库 → 缓存 → 微服务
```

### 3. 全栈路径

```
前端基础 → 后端基础 → 数据库 → 部署 → 项目实战
```

## 最佳实践

### 1. 目标分解

```
大目标 → 阶段目标 → 周目标 → 日任务
```

### 2. 实践驱动

```
学一个知识点 → 写一个小项目 → 总结复盘
```

### 3. 反馈循环

```
学习 → 实践 → 反馈 → 调整 → 继续
```

## 效率提升

### 1. 个性化

根据个人情况定制路径。

### 2. 实践化

注重动手实践。

### 3. 社区化

加入学习社区，互相督促。
