# AI 辅助移动端开发

## 核心原则

AI 移动端 = 跨平台 + 原生体验 + 性能优化

## 技术选型

### 1. 跨平台方案

| 方案 | 语言 | 适用场景 |
|------|------|----------|
| React Native | JavaScript | 快速迭代 |
| Flutter | Dart | 高性能 UI |
| .NET MAUI | C# | 企业应用 |

### 2. 原生开发

```
iOS: Swift/Swiftify
Android: Kotlin/Java
```

## Prompt 技巧

### 1. UI 组件生成

```markdown
- 通知状态
```

### 3. 性能优化

```markdown
请优化移动端性能:
- 列表渲染

```

## 最佳实践

### 1. UI 设计

**原则:**
- 平台适配
- 手势支持
- 无障碍设计

### 2. 性能优化

**策略:**
```
懒加载 → 虚拟列表 → 图片缓存 → 内存管理
```

### 3. 离线支持

**方案:**
```
本地存储 → 同步机制 → 冲突处理
```

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 卡顿 | 渲染优化 | 减少重绘 |
| 内存泄漏 | 未释放 | 检查资源 |
| 包太大 | 资源未优化 | 压缩资源 |
