# AI 辅助项目管理

## 核心原则

AI 项目管理 = 规划 + 执行 + 监控 + 优化

## 管理流程

```
需求分析 → 计划制定 → 任务分配 → 进度跟踪 → 风险控制
```

## Prompt 技巧

### 1. 需求分析

```markdown
请分析项目需求:
- 功能需求: 用户系统、订单系统
- 非功能需求: 性能、安全
- 约束条件: 时间、预算
```

### 2. 任务分解

```markdown
请分解开发任务:
- 项目: 电商平台
- 模块: 用户、商品、订单
- 工时: 2 周
```

### 3. 风险评估

```markdown
请评估项目风险:
- 技术风险: 新技术学习
- 人员风险: 核心成员离职
- 进度风险: 需求变更
```

## 敏捷实践

### 1. Scrum

**流程:**
```
Sprint Planning → Daily Standup → Sprint Review → Retrospective
```

### 2. Kanban

**原则:**
- 可视化工作流
- 限制在制品
- 管理流动

### 3. 看板设计

```
待办 → 进行中 → 测试 → 完成
```

## 最佳实践

### 1. 需求管理

```
需求收集 → 需求分析 → 需求确认 → 需求变更
```

### 2. 进度跟踪

```
每日更新 → 周报 → 里程碑 → 复盘
```

### 3. 风险管理

```
风险识别 → 风险评估 → 风险应对 → 风险监控
```

## 效率提升

### 1. 自动化

任务分配和进度跟踪自动化。

### 2. 可视化

项目状态可视化展示。

### 3. 数据驱动

基于数据做决策。
