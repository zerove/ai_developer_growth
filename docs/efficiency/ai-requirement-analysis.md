# AI 辅助需求分析

## 核心原则

AI 需求分析 = 用户理解 + 需求挖掘 + 方案设计

## 分析流程

```
用户调研 → 需求收集 → 需求分析 → 方案设计 → 验证确认
```

## Prompt 技巧

### 1. 用户故事

```markdown
请生成用户故事:
- 角色: 普通用户
- 功能: 购物车管理
- 场景: 添加、删除、修改数量
```

### 2. 需求文档

```markdown
请生成需求文档:
- 功能描述
- 验收标准
- 优先级
- 依赖关系
```

### 3. 原型设计

```markdown
请设计交互原型:
- 页面流程
- 交互逻辑
- 异常处理
```

## 需求类型

### 1. 功能需求

```
用户故事 → 用例 → 功能列表 → 验收标准
```

### 2. 非功能需求

```
性能 → 安全 → 可用性 → 可维护性
```

### 3. 约束条件

```
时间 → 预算 → 技术 → 法规
```

## 最佳实践

### 1. 需求优先级

```
MoSCoW 方法:
Must have
Should have
Could have
Won't have
```

### 2. 需求验证

```
原型验证 → 用户测试 → 反馈迭代
```

### 3. 需求变更

```
变更申请 → 影响分析 → 审批决策 → 实施验证
```

## 效率提升

### 1. 模板化

建立需求文档模板。

### 2. 自动化

自动生成用户故事。

### 3. 可视化

需求可视化展示。
