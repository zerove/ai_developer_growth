# AI 辅助团队协作

## 核心原则

AI 协作 = 沟通 + 协调 + 知识共享 + 冲突解决

## 协作模式

### 1. 异步协作

**工具:**
```
文档协作: Notion, Google Docs
代码协作: GitHub, GitLab
任务管理: Jira, Linear
```

### 2. 同步协作

**工具:**
```
即时通讯: Slack, Teams
视频会议: Zoom, Meet
白板: Miro, FigJam
```

### 3. 知识管理

**工具:**
```
文档库: Confluence, Wiki
代码库: GitHub Wiki
知识图谱: Obsidian
```

## Prompt 技巧

### 1. 会议纪要

```markdown
请生成会议纪要:
- 参会人员
- 讨论内容
- 决议事项
- 行动计划
```

### 2. 技术方案评审

```markdown
请评审技术方案:
- 方案可行性
- 风险点
- 改进建议
```

### 3. 代码审查

```markdown
请审查代码:
- 代码质量
- 最佳实践
- 潜在问题
```

## 最佳实践

### 1. 代码审查

```
提交 PR → 自动检查 → 人工审查 → 合并
```

### 2. 知识共享

```
技术分享 → 文档沉淀 → 代码注释
```

### 3. 冲突解决

```
问题识别 → 方案讨论 → 决策执行 → 复盘总结
```

## 效率提升

### 1. 自动化流程

减少重复性工作。

### 2. 标准化规范

统一代码和文档规范。

### 3. 工具集成

打通工具链，减少切换。
