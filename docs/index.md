##   快速开始

### 1. 选择学习路径

根据你的角色和目标，选择合适的学习路径：

- **初级开发者**: 心态层 → 学习层 → 工具层
- **中级开发者**: 效率层 → 治理层 → 案例研究
- **高级开发者**: 全部内容 + 贡献案例

### 2. 每日学习计划

```markdown
每日学习计划:
1. 阅读 1 篇文档 (15 分钟)
2. 实践 1 个技巧 (30 分钟)
3. 总结 1 个收获 (5 分钟)
```

### 3. 实践项目

将学到的知识应用到实际项目中：

1. 选择一个小项目
2. 应用 AI 工具
3. 记录效率提升
4. 分享经验
