# 代码阅读技巧

## 核心原则

代码阅读 = 自顶向下 + 抓大放小 + 持续实践

## 阅读方法

### 1. 自顶向下

**步骤:**
1. 阅读 README 了解项目
2. 查看目录结构
3. 找到入口文件
4. 理解核心流程

### 2. 抓大放小

**优先级:**
- 核心功能 > 辅助功能
- 主流程 > 边界情况
- 接口 > 实现

### 3. 带着问题读

**常见问题:**
- 这个函数做什么?
- 数据如何流动?
- 为什么这样设计?

## 阅读工具

### 1. IDE 功能

**VS Code:**
- Go to Definition
- Find References
- Call Hierarchy

### 2. 代码分析

**工具:**
```
- ctags: 代码索引
- graphviz: 依赖图
- pylint: 代码分析
```

### 3. 调试工具

**步骤:**
1. 设置断点
2. 单步执行
3. 观察变量
4. 理解逻辑

## 阅读流程

### 阶段 1: 快速浏览 (10 分钟)

**目标:** 了解项目全貌

**检查清单:**
- [ ] README 是否完整
- [ ] 目录结构是否清晰
- [ ] 入口文件在哪里

### 阶段 2: 核心理解 (30 分钟)

**目标:** 理解核心逻辑

**检查清单:**
- [ ] 核心功能是什么
- [ ] 数据如何流动
- [ ] 关键接口有哪些

### 阶段 3: 深入分析 (2 小时)

**目标:** 理解实现细节

**检查清单:**
- [ ] 算法如何实现
- [ ] 错误如何处理
- [ ] 性能如何优化

## 实践建议

### 1. 从小项目开始

**推荐项目:**
- CLI 工具
- Web 应用
- 库/框架

### 2. 做笔记

**笔记内容:**
- 项目架构
- 核心流程
- 设计决策

### 3. 参与开源

**参与方式:**
- 阅读源码
- 修复 bug
- 添加功能

## AI 辅助阅读

```markdown
请帮我分析这段代码:
```
