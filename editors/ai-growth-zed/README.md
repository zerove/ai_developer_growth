# 🚀 AI-Growth Zed Extension

Zed editor extension for **AI Developer Growth** and **JCode SDLC**.

## Features

- **JCode LSP Integration**: Connects Zed to JCode's multi-language rules engine and semantic code graph LSP server.
- **Architecture & Memory Commands**: Quickly generate dependency graphs and query session memory inside Zed.
- **Quality Gates**: Real-time linting and governance audits.

## Installation

Place this extension in your Zed extensions directory or load as a dev extension.
