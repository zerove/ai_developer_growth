# PRD: AI-Context-Sync (AI 上下文同步助手)

## 1. 产品愿景
在 AI 驱动的开发中，维持一个准确的 `CONTEXT.md` 和 `ADR.md` 是维持 AI 效率的关键。但手动更新这些文件极其繁琐且容易被遗忘。
**AI-Context-Sync** 旨在将此过程自动化：它像一个“项目记录员”，在后台监控代码变更，自动总结技术演进，并实时维护项目的灵魂文档。

## 2. 核心用户场景
- **场景 A (开发者提交代码)**：开发者完成一个功能并 `git commit`。AI-Context-Sync 检测到变更，分析代码差异，并更新 `CONTEXT.md` 中的“当前进度”部分。
- **场景 B (架构决策)**：开发者在 Commit 信息中标记 `#ADR`。工具自动触发 ADR 生成流程，引导开发者完成决策记录并写入 `docs/adr/`。
- **场景 C (新成员加入)**：新开发者克隆项目，阅读由 AI 持续维护的 `CONTEXT.md`，在 5 分钟内理解项目当前状态，无需翻阅数百个 Commit。

## 3. 核心功能 (MVP)
- **Git 变更监听**：通过 Git Hook (post-commit) 或定时扫描，捕获最近的 `diff`。
- **变更语义分析**：利用 LLM 将底层的 `diff` 转换为高层的“意图描述”（例如：将“修改了 3 个 API 接口”转换为“重构了用户鉴权逻辑以支持 OAuth2”）。
- **文档自动化更新**：
    - **CONTEXT.md**：自动更新【当前进度】、【已完成模块】、【待办项】。
    - **ADR.md**：识别决策类变更，自动草拟 ADR 文档。
- **配置化管理**：支持通过 `.ai-sync.json` 配置忽略的目录、使用的模型及更新频率。

## 4. 非功能性需求
- **极低干扰**：运行在后台，不阻塞开发流程。
- **上下文精准**：更新内容必须基于代码事实，严禁 AI 幻觉。
- **隐私安全**：支持本地模型 (Ollama) 或加密的 API Key 管理。

## 5. 成功指标
- **文档同步率**：`CONTEXT.md` 的更新频率与 Commit 频率的匹配度。
- **理解时间**：新成员通过阅读文档进入开发状态的时间显著降低。
