# AI Growth - Slack Bot

Slack bot for team learning management and skill assessment.

## Features

- **Skill Assessment**: Start assessments via chat commands
- **Progress Tracking**: Monitor team learning progress
- **Recommendations**: Get AI-powered learning suggestions
- **Team Commands**: Manage learning paths for teams

## Commands

| Command | Description |
|---------|-------------|
| `!growth assess` | Start skill assessment |
| `!growth progress` | View learning progress |
| `!growth recommend` | Get recommendations |
| `!growth help` | Show help |
