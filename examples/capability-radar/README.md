# AI 时代开发者能力雷达 - 使用指南

## 概览

`capability-radar` 是一个交互式 CLI 工具，帮助开发者在 AI 时代评估自己的能力水平，生成个性化成长雷达图和建议。

## 安装

```bash
cd examples/capability-radar
pip install -e .
# 或直接运行
python -m src.cli
```

## 使用方式

### 交互式评估 (推荐)
```bash
capability-radar
# 或
python -m src.cli
```

会引导你完成 5 个维度 × 4 道题 = 20 道题的评估，每题选择最贴切的等级 (L0-L4) 和置信度 (1-5)。

### 批量导入评估
```bash
capability-radar -i answers.json
```
适合 CI/CD 集成或团队批量评估。

### 查看演示
```bash
capability-radar --demo
```

## 评估维度

| 维度 | 核心关注点 | L0-L4 定义 |
|------|-----------|------------|
| **问题定义与产品思维** | 从"实现需求"到"定义值得解决的问题" | L0: 接受需求 → L1: 澄清需求 → L2: 发现真问题 → L3: 定义产品 → L4: 战略洞察 |
| **架构决策与系统设计** | 从"无设计"到"平台化思维" | L0: 无设计 → L1: 模块设计 → L2: 系统设计 → L3: 技术权衡 → L4: 平台化思维 |
| **AI 协作与提示工程** | 从"不用 AI"到"元能力构建" | L0: 不用 AI → L1: 问答式 → L2: 结构化协作 → L3: 工作流编排 → L4: 造工具/标准 |
| **工程严谨性与质量文化** | 从"能跑就行"到"文化塑造" | L0: 能跑就行 → L1: 基础规范 → L2: 质量内建 → L3: 度量驱动 → L4: 文化塑造 |
| **学习与知识内化** | 从"依赖 AI"到"知识创造" | L0: 依赖 AI → L1: 速查式学习 → L2: 主动内化 → L3: 模式识别 → L4: 知识创造 |

## 输出结果

- **雷达图** (ASCII) - 可视化五维能力分布
- **维度详情** - 每维度得分、等级、置信度
- **个性化建议** - 基于最弱维度的优先改进建议
- **成长路径** - 季度 OKR 建议

## 集成建议

### Onboarding 集成
新员工入职第一周完成评估，建立基准线，季度复测。

### 招聘筛选
面试前发送评估链接，结果作为技能基准参考。

### 晋升通道
L2→L3 要求雷达图全维度 ≥ L2；L3→L4 要求 ≥ L3 且有至少 1 个维度达 L4。

### 团队雷达
团队定期匿名聚合雷达图，识别团队短板，制定培训计划。

## CI/CD 集成

```yaml
# .github/workflows/skill-assessment.yml
name: Team Skill Assessment
on:
  schedule:
    - cron: '0 0 * * 1'  # Every Monday
  workflow_dispatch:

jobs:
  assess:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: pip install -e examples/capability-radar
      - run: capability-radar --demo > radar-report.md
      - uses: actions/upload-artifact@v4
        with:
          name: team-radar-report
          path: radar-report.md
```
