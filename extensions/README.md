# Extensions Overview

本项目包含 4 个 IDE/编辑器扩展，用于在开发环境中集成 ADG 治理规则。

| 扩展 | 平台 | 目录 | 状态 |
|------|------|------|------|
| ADG Language Rules | Zed | `zed-adg/` | Rust 扩展 |
| AI Language Rules | Zed | `ai-language-rules/` | Python LSP, Rust 扩展 |
| AI Language Rules | VS Code | `vscode-ai-language-rules/` | JavaScript 扩展 |
| ADG LSP | VS Code | `vscode-adg/` | TypeScript 扩展 |

每个扩展的详细使用说明在其各自目录的 `README.md` 中。
