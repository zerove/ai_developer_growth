    AI 辅助技术写作¶

    核心原则¶

    技术写作 = 准确性 + 可读性 + 实用性

    写作流程¶

    主题确定 → 大纲设计 → 内容生成 → 审核优化 → 发布

    Prompt 技巧¶

    1. 文章生成¶

    请撰写技术文章:
- 主题: Python 异步编程
- 目标读者: 中级开发者
- 字数: 2000 字
- 结构: 问题-方案-代码-总结

    2. 大纲设计¶

    请设计文章大纲:
- 主题: 微服务架构
- 要点: 设计原则、技术选型、最佳实践
- 篇幅: 3000 字

    3. 内容优化¶

    请优化文章:
- 提升可读性
- 增加代码示例
- 添加最佳实践

    文章类型¶

    1. 教程类¶

    结构: 

    介绍 → 环境准备 → 步骤详解 → 常见问题 → 总结

    2. 原理类¶

    结构: 

    问题背景 → 核心概念 → 原理解析 → 实际应用 → 总结

    3. 实战类¶

    结构: 

    项目介绍 → 技术选型 → 实现过程 → 效果展示 → 总结

    最佳实践¶

    1. 代码示例¶

    原则: - 完整可运行 - 注释清晰 - 错误处理

    2. 图表辅助¶

    原则: - 架构图 - 流程图 - 时序图

    3. SEO 优化¶

    原则: - 标题吸引 - 关键词布局 - 内链外链

    效率提升¶

    1. 模板化¶

    建立文章模板库。

    2. 素材库¶

    积累代码片段和图表。

    3. 批量生成¶

    批量生成系列文章。
