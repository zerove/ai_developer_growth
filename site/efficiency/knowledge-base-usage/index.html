    OpenCode 知识库使用方案 (Knowledge Base Usage Plan)¶

    将35篇知识文档转化为开发实践。

    概述¶

    本文档提供将知识库内容系统化应用于 OpenCode 开发的完整方案，包括文档引用规则、工作流集成、自动化配置。

    1. 文档引用规则¶

    1.1 文档分类与使用场景¶

    文档类型 使用场景 引用方式 优先级
    认知层 决策、规划 项目开始时 高
    学习层 技能提升 遇到新领域时 中
    效率层 日常开发 每次开发 高
    工具层 工具选型 选择工具时 中
    案例库 参考借鉴 相似场景时 低

    1.2 文档引用模板¶

    # OpenCode 任务引用模板

## 任务描述
[具体任务]

## 引用文档

- 避免文档中提到的反模式

    3.2 自动引用脚本¶

    scripts/load-docs.sh: 

    #!/bin/bash

# 根据任务类型加载相关文档
load_docs() {
    local task_type=$1

    case $task_type in
        "requirement")
            echo "加载需求分析文档..."
            cat docs/mindset/product-thinking.md
            cat docs/efficiency/full-cycle-workflow.md
            ;;
        "architecture")
            echo "加载架构设计文档..."
            cat docs/efficiency/context-engineering.md
            cat docs/efficiency/multi-agent-patterns.md
            ;;
        "coding")
            echo "加载编码实现文档..."
            cat docs/efficiency/full-cycle-workflow.md
            cat docs/efficiency/anti-patterns.md
            cat docs/efficiency/token-optimization.md
            ;;
        "testing")
            echo "加载测试验证文档..."
            cat docs/efficiency/automated-bug-fixing.md
            cat docs/efficiency/ai-security-review.md
            ;;
        "deployment")
            echo "加载部署上线文档..."
            cat docs/efficiency/full-cycle-workflow.md
            cat docs/efficiency/metrics-framework.md
            ;;
        *)
            echo "加载全部文档..."
            cat docs/**/*.md
            ;;
    esac
}

# 使用示例
# ./load-docs.sh requirement
# ./load-docs.sh coding

    5. 度量与优化¶

    5.1 文档使用度量¶

    度量指标: - 文档引用频率 - 文档应用效果 - 文档更新及时性 - 文档覆盖完整性

    度量工具: 

    # 记录文档引用
def log_doc_usage(doc_name, task_type, success_rate):
    # 存储到数据库
    db.insert({
        'doc_name': doc_name,
        'task_type': task_type,
        'success_rate': success_rate,
        'timestamp': datetime.now()
    })

    5.2 文档优化流程¶

    1. 收集使用反馈
   └── 开发者反馈、效果数据

2. 分析问题
   └── 识别低效文档、缺失内容

3. 优化文档
   └── 更新内容、补充案例

4. 验证效果
   └── A/B 测试、效果对比

5. 持续改进
   └── 定期回顾、迭代优化

    6. 常见问题¶

    Q1: 文档太多，如何选择？¶

    选择策略: - 根据任务类型选择核心文档 - 使用自动化工具辅助选择 - 建立文档优先级机制

    Q2: 文档过时如何处理？¶

    更新机制: - 定期审查文档时效性 - 建立文档更新流程 - 使用版本控制管理文档

    Q3: 如何确保文档被使用？¶

    推广策略: - 集成到开发流程 - 建立使用激励 - 定期培训和分享

    总结¶

    核心原则: 1. 场景驱动: 根据任务类型选择文档 2. 自动化优先: 使用工具辅助文档加载 3. 持续优化: 根据反馈迭代文档 4. 效果度量: 量化文档应用价值

    关键行动: 1. 建立文档引用规则 2. 配置自动化工具 3. 集成到开发流程 4. 度量和优化效果
