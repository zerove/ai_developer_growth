# 新员工入职清单 - 能力雷达集成版

> 新员工入职第一周任务清单，包含能力雷达评估集成

---

## 📋 入职前准备 (HR/导师准备)

- [ ] 发送入职欢迎邮件 (含能力雷达介绍链接)
- [ ] 准备欢迎包：能力雷达介绍单页 + `examples/capability-radar/README.md`
- [ ] 确认导师已完成雷达种子用户培训
- [ ] capability-radar 已部署/可访问
- [ ] 新员工账号已创建
- [ ] 示例 `answers.json` 模板已准备

---

## 📅 入职第 1 周执行清单

### Day 1: 入职首日 (环境搭建 + 雷达介绍)
- [ ] 09:00-09:30 环境搭建：克隆 capability-radar 仓库，安装依赖
- [ ] 09:30-10:00 工具演示：Buddy 演示 capability-radar 基本用法
- [ ] 10:00-10:30 阅读文档：阅读 `examples/capability-radar/README.md`
- [ ] 10:30-11:00 试跑演示：运行 `--demo` 模式体验完整流程
- [ ] ✅ **交付物**: 环境就绪，能运行 `python -m src.cli --demo`

### Day 2-3: 完成自评 (约 15-20 分钟)
- [ ] 阅读题目：仔细阅读每题的 5 个等级描述
- [ ] 选择等级：基于真实经历选择最贴切等级
- [ ] 标注置信度：1-5 分表示确信程度
- [ ] 导出报告：保存 JSON 和 Markdown 报告
- [ ] ✅ **交付物**: `radar-report-<姓名>-<日期>.md` + `.json`

### Day 4: 导师 1-on-1 复盘 (60 分钟)
- [ ] 10 分钟：破冰 & 设定期望 (非考核，是成长规划)
- [ ] 15 分钟：雷达图解读 - 逐维度复盘：得分、证据、差距
- [ ] 15 分钟：深度挖掘 - 针对最弱/最强维度深度讨论
- [ ] 10 分钟：识别盲区 - 对比自评 vs 导师视角
- [ ] 10 分钟：制定成长计划 - 确定下季度重点提升 1 个维度
- [ ] ✅ **交付物**: 完成《新员工成长计划单》，导师标注"导师视角"等级

### Day 5: 制定季度成长 OKR
- [ ] 制定季度成长 OKR (基于雷达最弱维度)
- [ ] 确定 KR 关键结果和截止日期
- [ ] 约定下次复盘时间 (建议 2 周后)
- [ ] ✅ **交付物**: 季度成长 OKR 文档

---

## 📅 入职满月复盘 (Day 30)
- [ ] 雷达复测对比 (入职时 vs 当前)
- [ ] OKR 进度检查 (KR 完成度、阻塞项、调整计划)
- [ ] 难点复盘 (遇到的困难、导师支持、资源需求)
- [ ] 下月重点确定
- [ ] ✅ **交付物**: 月度复盘记录

---

## 📅 试用期结束评估 (Day 90)
- [ ] 雷达全维度复测
- [ ] 无单维度低于目标等级 -1
- [ ] 完成季度 OKR 至少 80%
- [ ] 导师/主管一致同意通过
- [ ] ✅ **交付物**: 试用期评估报告
